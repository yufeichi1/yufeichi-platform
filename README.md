# Yufeichi Platform

## 项目简介

基于 Spring Boot 3 + Vue 3 的个人博客、项目展示与后台管理平台。

## 技术栈

### 前端

Vue 3、Vite、TypeScript、Element Plus、Axios、Pinia、Vue Router

### 后端

Java 21、Spring Boot 3、Spring Security、JWT、MyBatis-Plus、MySQL、Redis、Flyway

### 部署

Ubuntu、Nginx、Docker、Docker Compose、systemd、HTTPS

## 项目模块

- 前台首页
- 技术博客
- 项目展示
- 留言板
- 后台管理
- 登录认证
- RBAC 权限
- 文件上传
- ### 日志管理
