# Yufeichi Platform：个人内容网站与 AI 应用实践

Yufeichi Platform 是我的个人全栈项目，用于展示文章和项目，并在原有内容管理能力上实践 AI 应用工程。后端固定使用 Java 21，采用 Spring Boot 3、Spring Security 和 MyBatis-Plus；前端使用 Vue 3、TypeScript 和 Vite。MySQL 保存业务数据，Redis 支持认证与请求配额，数据库结构由 Flyway 管理。

网站的 AI 功能围绕三个具体场景构建。文章摘要助手根据编辑器中的正文生成候选摘要，由作者核对和采用，不自动保存或发布文章。站内知识问答只检索已发布文章与公开项目，利用独立的 PostgreSQL/pgvector 索引获取相关片段，并返回可以打开原文的来源。只读助手可以调用文章搜索、项目搜索、文章详情和项目详情四种工具，完成受限的多步骤查询。

聊天模型与向量模型分别配置，通过后端调用外部服务，API 密钥不发送给浏览器。摘要面向有文章编辑权限的用户；索引管理使用独立权限。站内问答在检索和回答前后核对源内容的公开状态与版本，减少下架或修改后的旧内容继续出现在回答中的风险。工具只提供公开内容查询，不执行写入、任意 SQL 或外部 URL 请求。

这次实践重点是将模型接入已有业务系统：控制输入与输出、限流和超时、取消长请求、验证来源、处理索引同步失败，以及在 AI 不可用时保持原网站功能可用。测试环境与生产数据隔离，模型桩用于确定性回归，真实模型评测单独记录。评测中的构造内容属于测试夹具，不代表实际业务规模，也不作为性能宣传。

这是一个个人项目，不声称具有商业客户、企业工作经历或未经测量的吞吐量。后续会继续根据实际使用体验完善内容与交互，并保留实现、测试和部署的真实记录。
