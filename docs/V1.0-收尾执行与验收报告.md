## 问题与修复

| 问题 | 原因 | 修复和实测 |
|---|---|---|

| 无正式定时备份和失败反馈 | 仅有迁移前备份及一次性 Day7 归档 | 新增 `backup.sh`、service/timer、OnFailure handler；真实 service 成功，故意缺失 Compose 的失败演练也通过 |
| 恢复仅核对数量/哈希 | 原记录没有启动恢复后的应用，也没有可读文章/项目关系 | 创建标明用途的 API 验收数据，备份后导入独立 MySQL；启动非 root Java21 + 独立 Redis，验证登录、关联、读写、上传和文件链接 |
| 原回滚候选上传图片 403 | `31a551c` 创建临时文件时为 0600，Nginx 的 www-data 无读权限 | 实际复现后自动恢复当前版；将已有 `7c24911` 的 0640 修复回移到该候选，重新无跳过测试打包，再验证回滚读写/新上传 |
